# RITB Data Science - Document Verification Tracker

## 📌 Project Overview
This repository contains the **Document Verification Ledger** for the Data Science department at RITB. The system is designed to streamline the administrative workflow of auditing and verifying student credentials during the admission and registration process.

## 📊 Tracked Parameters
The system monitors the submission and verification status of several critical academic and identity documents, including:

* **Academic Transcripts:** SSLC Marks Card, 1st PUC, and 2nd PUC (12th Grade) records.
* **Transfer & Identity:** Transfer Certificate (TC), Migration Certificate (for non-local students), and Study Certificate.
* **Entrance & Admission:** Admission Order copies and rank tracking.
* **Demographics:** Categorization by seat type (KCET/Management), State status (Karnataka/Non-Karnataka), and Reservation categories (OBC, SC/ST, 2A, etc.).

## 🛠 Usage
The data is maintained in a structured Excel format (`.xlsx`) to ensure:
1.  **Data Integrity:** Quick identification of missing or pending documents.
2.  **Filterability:** Sorting students based on seat category or state status.
3.  **Audit Readiness:** Providing a clear snapshot for university compliance.

## 📂 File Structure
* `RITB_Data_Science_Docs.xlsx`: The primary data sheet containing student records and verification flags.
* `README.md`: Project documentation and overview.
